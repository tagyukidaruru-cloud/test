# みんなで投稿を共有できるようにする手順（約5分・全部日本語）

Google の無料サービス「Firebase」を使います。
画面はすべて日本語で、お持ちのGmailアカウントでそのまま使えます。

## 1. Firebaseを開く

1. ブラウザで https://console.firebase.google.com を開く
2. Googleアカウント（Gmail）でログイン

## 2. プロジェクトを作る

1. 「**プロジェクトを作成**」をクリック
2. プロジェクト名: `style-archive` と入力 → 「続行」
3. 「このプロジェクトで Google アナリティクスを有効にする」は **オフ** にする → 「プロジェクトを作成」
4. 1分ほど待って「続行」

## 3. データベースを作る

1. 左メニューの「**構築**」→「**Firestore Database**」をクリック
2. 「**データベースを作成**」をクリック
3. ロケーション: 「**asia-northeast1（東京）**」を選ぶ → 「次へ」
4. 「**本番環境モードで開始**」のまま → 「作成」
5. できあがったら上の「**ルール**」タブをクリック
6. 中身を全部消して、下の内容に貼り替える → 「**公開**」をクリック

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

## 4. 接続情報をコピーして教えてください

1. 左上の「**⚙（歯車）**」→「**プロジェクトの設定**」をクリック
2. 下にスクロールして「**マイアプリ**」の欄にある「**</>**」（ウェブ）アイコンをクリック
3. アプリのニックネーム: `style-archive` と入力 → 「**アプリを登録**」
4. 画面に `const firebaseConfig = { ... }` というコードが表示されます
5. **その `{` から `}` までを全部コピーして、チャットに貼り付けてください**

例（こういう形のものです）:

```
const firebaseConfig = {
  apiKey: "AIza......",
  authDomain: "style-archive-xxxx.firebaseapp.com",
  projectId: "style-archive-xxxx",
  storageBucket: "style-archive-xxxx.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};
```

これを受け取ったら、アプリをデータベースにつないで動作確認まで行い、
そのあと共有リンク（URL）の発行までご案内します。

## 知っておいてほしいこと

- この接続情報は公開しても問題ない種類のものです（そういう設計です）
- ただしこのアプリは**パスワードなしの簡易アカウント**なので、
  リンクは信頼できるメンバーだけに共有してください
