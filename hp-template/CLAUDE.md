# ホームページ作成テンプレート — Claude 向け作業ルール

このフォルダはホームページ制作用のテンプレート。ユーザーは非エンジニアなので、専門用語を避けて日本語でやり取りすること。

## フォルダ構成

- `参考デザイン/` — ユーザーが集めたデザインの参考スクショ。**作業前に必ず全部 Read して雰囲気を把握する**
- `素材/` — ロゴ・写真・掲載する文章。ここにあるものだけを使う(勝手にダミー画像で済ませない。足りなければユーザーに聞く)
- `site/` — 生成物の出力先。`index.html` を起点にする

## 技術方針

- **単一の HTML ファイル + CSS/JS 埋め込み**を基本とする(ビルドツール・フレームワーク不使用)
- ページが増える場合のみ `site/` 内に HTML を追加し、相互リンクする
- 画像は `素材/` から `site/img/` にコピーして相対パスで参照
- Google Fonts 可。外部 CDN ライブラリは最小限

## デザイン品質基準(アワード級を目指す)

1. **タイポグラフィ**: 見出しは大胆に大きく。日本語は Noto Sans JP / Zen Kaku Gothic 等、英字見出しとの組み合わせも検討
2. **余白**: 詰め込まない。セクション間は贅沢に space を取る
3. **配色**: 参考デザインから抽出。ベース+アクセント1色に絞る
4. **動き**: スクロール連動のフェードイン、hover の反応など控えめで上質なアニメーション(IntersectionObserver + CSS transition)
5. **レスポンシブ必須**: モバイル(375px)とデスクトップ両方をプレビューで確認してから完了報告する

## プレビュー方法(重要: macOS の制限回避)

プレビューサーバーのプロセスは Downloads フォルダを直接読めない(TCC 制限)。必ず以下の手順:

1. Bash: `cp -R /Users/uuto/Downloads/test/hp-template/site/. /private/tmp/claude-501/-Users-uuto-Downloads-test/hp-preview/`
2. `preview_start` で launch.json の `hp-preview` を起動(tmp のコピーを配信、port 4180)
3. `site/` を編集するたびに 1 のコピーを再実行してからリロード

## 作業フロー

1. `参考デザイン/` と `素材/` を読む
2. 構成案(セクション一覧)を3行以内で提示 → 承認後に作る
3. 生成 → プレビューで表示確認(モバイル/デスクトップ両方)
4. 完了報告は簡潔に:【変更内容】/【変更ファイル】/【確認事項】

## 出力ルール(ユーザー指定)

- 長い説明・進捗報告は不要。結論のみ簡潔に
- 推測で進めず、素材や情報が足りないときだけ質問する
