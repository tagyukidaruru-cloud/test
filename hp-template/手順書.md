# ホームページ作成の手順書

Claude Code でホームページを作るときの流れです。毎回この順番でやればOKです。

## 事前準備(あなたがやること)

1. **参考デザインを集める**
   - 好きな雰囲気のサイトのスクリーンショットを撮る
   - 探す場所: [Awwwards](https://www.awwwards.com/)、[Pinterest](https://www.pinterest.jp/)、[SANKOU!](https://sankoudesign.com/)(日本のサイト集)
   - 撮ったスクショを `参考デザイン` フォルダに入れる(2〜5枚が目安)

2. **素材を用意する**
   - ロゴ・写真・載せたい文章(お店の名前、メニュー、住所など)を `素材` フォルダに入れる
   - 文章はメモ帳(.txt)に書いて入れるだけでOK

## 作成(Claude Code に指示すること)

3. **Claude Code を開いて、このフォルダ(hp-template)で指示する**

   言い方の例:
   > 参考デザインフォルダのスクショの雰囲気で、〇〇(お店・サービス名)のホームページを作って。素材フォルダの写真と文章を使って。

4. **プレビューで確認する**
   > プレビューで見せて

   と言えば Claude がブラウザで表示してくれます。

5. **気になるところを日本語で伝えて直してもらう**

   言い方の例:
   - 「文字をもっと大きく、高級感を出して」
   - 「スクロールしたときにふわっと出てくる動きをつけて」
   - 「スマホで見たときのレイアウトを確認して直して」

6. **完成**
   - できあがったファイルは `site` フォルダに入っています
   - `site/index.html` をダブルクリックすればブラウザでいつでも見られます

## コツ

- 一度に全部直そうとせず、1つずつ指示する
- 「アワード受賞サイトみたいに」「余白を贅沢に」「動きをつけて」などの言葉が効きます
- 気に入らなければ「さっきの方が良かった、戻して」でOK
